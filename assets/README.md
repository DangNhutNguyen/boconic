# Assets & Evidence Directory

Thư mục này dành riêng để lưu trữ các tài liệu minh chứng, hình ảnh kiến trúc, ảnh chụp màn hình kiểm thử và bằng chứng vận hành của nền tảng Boconic.

### Các loại tài liệu có thể đưa vào thư mục này:
- 📸 **Screenshots**: Ảnh chụp giao diện Admin Console, màn hình tương tác Telegram Bot, thông báo luồng mượn trả.
- 📊 **Kiến trúc & Sơ đồ**: Sơ đồ luồng (Flowcharts), ERD diagram, Architecture diagrams.
- 📑 **Minh chứng kiểm thử**: Log kết quả chạy test suite, báo cáo smoke test, chứng nhận bảo mật.
- 📜 **Tài liệu dự án**: Slide thuyết trình, hồ sơ kỹ thuật, biên bản bàn giao.

*(Thư mục này hiện tại được giữ sạch và đã sẵn sàng để người dùng bổ sung các minh chứng riêng bất cứ lúc nào).*
